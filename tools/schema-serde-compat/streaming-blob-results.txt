RPCv2 CBOR streaming blob implementation and verification (2026-10-14)

Implemented:
- ByteStream stays the server output type. Generated glue extracts it and passes
  the modeled member schema (generation-time index, no runtime search) to the protocol.
- Private server runtime OuterSerializer opens the map through write_struct and
  invokes the existing generated serialize_members. MemberSerializer delegates
  every value write to the existing configured CBOR codec, including nested values.
- Prefix / Streaming / Suffix / Done body states emit definite chunks within an
  indefinite byte string. No collection, no known encoded size, no Content-Length.
  Pending propagates; empty chunks yield; errors terminate without closing markers.
- Removed the generated async output collection, future alias and buffered helper.
  Updated protocol implementations, wrappers, test doubles and checked-in example glue.
- Incoming preparation/deserialization, event framing, client behavior, shared codec,
  ShapeSerializer and legacy router interfaces were not changed by this task.
