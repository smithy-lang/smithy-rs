# aws-smithy-schema-derive

Derive macro for hand-written [aws-smithy-schema](https://crates.io/crates/aws-smithy-schema) shapes. Use it through the `derive` feature of `aws-smithy-schema` rather than depending on this crate directly.

<!-- anchor_start:footer -->
This crate is part of the [AWS SDK for Rust](https://awslabs.github.io/aws-sdk-rust/) and the [smithy-rs](https://github.com/smithy-lang/smithy-rs) code generator. In most cases, it should not be used directly.
